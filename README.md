# 🧮 MathBar: The Gamified AI Math Tutor

**MathBar** is an interactive educational platform built with **Python** and **Streamlit**. It combines gamified quizzes, a global leaderboard system, and a hybrid AI tutor (Online & Offline) to help students master advanced mathematics.

## 🚀 Features

* **🎮 Gamified Quizzes:** Subjects include Calculus, Linear Algebra, Discrete Math, and Probability.
* **🏆 Global Leaderboard:** Real-time ranking system connected to **Google Sheets**. Tracks XP and player names.
* **🤖 Hybrid AI Tutor:**
    * **☁️ Online Mode:** Powered by **Google Gemini 1.5 Flash** for high-speed, intelligent math assistance.
    * **🏠 Offline Mode:** Powered by **GPT4All** (Local LLM) for privacy-focused, internet-free learning.
* **xp XP System:** Earn XP for every correct answer and climb the ranks!

## 🛠️ Tech Stack

* **Frontend:** Streamlit
* **Data Handling:** Pandas
* **Database:** Google Sheets API (via `gspread`)
* **AI Models:** Google Generative AI (Gemini), GPT4All
